# 3SNET Widget Test

## Описание
Автоматизированный тест проверяет работу страницы

Покрытие теста:
- выбор тематики и стран;
- ввод размеров виджета;
- настройка радиокнопок;
- генерация превью;
- копирование сгенерированного кода.

## Требования
- Python 3.13.0
- Playwright 1.44.0 (будет установлен через pip)

## Установка
Клонируем репозиторий и устанавливаем зависимости:

```bash
git clone <https://github.com/Fabu1o/3snet.git>
cd 3snet-widget-test
pip install -r requirements.txt
playwright install
```

## Для запуска требуется зайти в файл и прописать команду 

python main.py
